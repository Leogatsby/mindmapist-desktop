# MindMapist Desktop

Installers and auto-update files for the MindMapist desktop app (Windows · macOS · Linux).

- Download the latest version from [Releases](../../releases/latest).
- The app opens the MindMapist web app (https://app.mindmapistai.com), so new features arrive without reinstalling.
  Installed apps update themselves from these releases when the desktop shell changes.

This repository holds release files only — no source code.
